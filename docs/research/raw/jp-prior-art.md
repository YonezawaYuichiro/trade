## 結論(5〜10 行)

1. **そのまま写せる一次ソースが 1 つある。** JPX 公式の `J-Quants/JPXTokyoStockExchangePrediction`(Apache-2.0)に、Kaggle「JPX Tokyo Stock Exchange Prediction」(2022 年)上位 10 チームのコードと解説が順位・スコアつきで入っている。4 位と 9 位は機械学習を使わない 1〜2 行のルール、5 位は特徴量 8 個の LightGBM で、どれも短時間で再現できる。
2. **日本株の日次予測で繰り返し報告されている効き目は「短期リバーサル」。** 前日リターン(4 位・6 位)、2 日リターン(5 位)、当日の寄り→引けリターン(9 位)の逆張りが上位に並び、2026 年 3 月の検証スライド(TOPIX500、寄り→引け目的、テスト 2025/1〜2026/2)でも、LLM に戦略を作らせると前日リバーサル系ばかり量産されたと報告されている。
3. **寄り→引けを直接予測する日本語の査読前研究がある。** 中川ほか(2026、人工知能学会 金融情報学研究会)の日米業種リードラグ。米国業種 ETF の当日終値リターンから、日本の業種 ETF の翌営業日の寄り→引けを予測し、年率 23.79%・R/R 2.22(2010〜2025 年データ)と報告。ただし個人による再現では年率 11.99%・R/R 1.09 に下がり、2024 年以降は −24%、実運用 27 営業日は −17% だった。
4. **現実的な的中率の相場は 50〜56%。** 公開予想の実績(投資の森の日経平均 AI 予想)は 2024 年 52%、2025 年 56%、2026 年 10 月 13 日まで 55%。個別株の方向予測は 3 営業日で 51〜53%、1 週間で 56% 前後という自己申告が多い。60% を大きく超える数字は、検証の仕方に問題があるものが目立った。
5. **Kaggle 上位の順位はかなり運に左右されている。** 4 位の作者自身が決め手を「運」と書き、2 位・3 位のコードには銘柄をまたいだ移動窓や検証データの重複といった不備がある。上位解法は「何が効いたか」の候補集として使い、成績の保証とは見なさない。
6. **失敗談の型は共通している。** 当日終値を含む特徴量で当日の寄りを判定(先読み)、コストを片道だけ計上、銘柄方向での学習/検証分割、ルールを同じデータで選んで同じデータで成績発表、特徴量や学習期間を増やして悪化、の 5 つ。
7. **データの前提が変わっている。** J-Quants の Free プランは 12 週間遅延で、当日予測には使えない。当日分が要るなら Light(月 1,650 円)以上。分足・ティックは別売り(月 5,500 円)。V1 のトークン認証は廃止済みで、2023 年頃の個人ライブラリは動かない可能性が高い。
8. **商用 AI 予想(兜予報、Phantom、株予報 Pro、Yahoo!ファイナンス、みんかぶ)の公表精度は確認できなかった。** 株予報 Pro は的中率を掲載しておらず、Phantom の旧ドメインは転送先が別サイトで、運営会社サイトは初期ページ表示だった。
9. **このプロジェクトの二本立て(機械学習+docs ルール)は、日本の実務家の推奨と一致する。** AlpacaTech の北山氏は「ベースラインは機械学習以外で作る」、UKI 氏は「実運用では 2〜3 指標のルールベースに落とし込む」と書いている。

### 4. heegle「機械学習による株価予想の十八手」(決算まわりのドメイン知識)

docs の因果ルールに入れやすい順に並べる。閾値の数値はほとんど記事に書かれていない。

1. サプライズ: 絶対値ではなく事前予想との乖離を見る。2 倍増収でも予想が 3 倍なら売られる。
2. 変化率の分母: 差額を時価総額や数年平均売上で割る。赤字↔黒字の転換はフラグで別扱い。
3. 理由のない事前上昇(情報漏れの疑い)を検出する。
4. 欠損は上位の利益指標の変化率で補う(売上→営業利益→経常利益→最終利益)。
5. 四半期の季節性を係数にして年間を推定する。
6. 決算と来期予想が同時に出たら来期予想を重く見る。
7. 経営者の強気度: 企業ごとの過去の予想と実績の乖離から予想の信頼度を作る。保守的な会社は上方修正しやすい。
8. 四半期進捗率から通期予想の修正を先回りする。
9. 会計基準が変わったら別会社として扱う。
10. 決算期変更は 12 か月換算する。
11. 創薬ベンチャーなど特異業種は除外するかフラグを立てる。
12. 権利付き最終日: 2019-07-18 以降は権利確定日の 2 営業日前(それ以前は 3 営業日前)。東証の休場日カレンダーが要る。
13. 記念配当は一過性として均す。
14. 株主優待を金額換算し、権利落ち後の下落に織り込む。
15. 株式分割・併合: 配当利回りや値幅上限の判定がずれる。データ提供元ごとに補正状況が違う。
16. 連鎖的な売り: 信用取引の強制決済で下落が数日加速する。
17. チャート理論は根拠が薄くても、多くの人が従うことで自己実現する。
18. マクロ影響は目的変数から差し引いて学習する。

- 2026 年の 102 勝 85 敗は 54.5%。件数 187 では 50% との差は統計的に区別できない(筆者の計算で z ≈ 1.24)。3 年合計の 365 勝 310 敗(54.1%)でようやく z ≈ 2.1 になる。

- したがって採点は「日数」で数え、月単位の勝率に一喜一憂しない設計が必要。

## 因果ルール候補

確度の付け方: A = 複数の査読研究で再現(本ノートの調査範囲では学術文献を確認していないため、A は付けていない)、B = 単独研究または実務統計・コンペ結果あり、C = 経験則・未検証。
入手時刻のうち「米国市場の引けは日本時間の朝 5 時(夏時間)または 6 時(冬時間)」「東証の立会は 9:00〜15:30」は一般知識で書いており、今回は開いて確認していない。

### R1. 前日リターンのクロスセクション・リバーサル
- IF 前日の終値リターンが、同じ日の対象銘柄群の中で下位 10% に入る → THEN その銘柄は市場平均に対して相対的に上、上位 10% は相対的に下。時間軸は翌日〜翌々日。大きさは日次で数十 bp の相対差(出典に銘柄単位の数値はない)。
- なぜ: 一時的な売買の偏り(流動性の提供に対する対価)と短期の過剰反応の戻り。UKI 氏は銘柄固有の残差リターンに強いリバーサルがあると書いている。
- 根拠: Kaggle JPX 4 位(ルールのみで非公開スコア 0.347、2022-07〜10 の約 3 か月、約 2,000 銘柄)。6 位(前日終値との差の 1 特徴量、0.308)。5 位(2 日リターンが最重要の特徴量)。Morim スライド(TOPIX500、2025-01〜2026-02、寄り→引け目的でリバーサルのみの戦略が順位相関 Sharpe 0.13)。https://github.com/J-Quants/JPXTokyoStockExchangePrediction 、https://speakerdeck.com/morim/kagglerga
- 効かなくなる条件: 市場全体が下落した日(R12)。決算・材料による値動き(情報による動きは戻らない)。高ボラ局面(5 位作者の推測。解説者の追試では明確でなかった)。低位株・低流動性に偏るので、実際には売買できない銘柄で成績が出ている可能性。
- 判定に必要なデータと入手時刻: 前日までの調整済み終値。前日の引け後に確定。
- 確度: B

### R2. 当日の寄り→引けリターンのリバーサル
- IF 前営業日の寄り→引けリターンが対象銘柄群の下位 → THEN 翌営業日以降に相対的に上(上位は相対的に下)。
- なぜ: 日中に付いた値動きは、その日の需給(大口の執行、個人の追随)による行き過ぎを含みやすい。
- 根拠: Kaggle JPX 9 位(ルールのみ、非公開 0.281。ただし学習期間では 0.054)。Morim スライドの優勝戦略で寄り→引けの重みが −0.8 と最大の負。同スライドの 2 位・4 位・5 位チームも寄り→引けの逆張りを中核にしている。
- 効かなくなる条件: R1 と同じ。学習期間と非公開期間で成績が 5 倍違うので、期間依存が大きい。
- 判定に必要なデータと入手時刻: 前営業日の調整済み始値・終値。前日の引け後。
- 確度: B

### R3. 配当権利落ち日の機械的な下落
- IF 当日が配当の権利落ち日 → THEN 未調整の終値ベースの前日比は、理屈の上では 1 株配当 ÷ 株価の分だけ低くなる。主に寄り付きのギャップとして現れる。
- なぜ: 権利落ち後に買った人は配当を受け取れないので、その分だけ理論価格が下がる。
- 根拠: Kaggle JPX 4 位が配当予定のある銘柄を売り側の端に置くルールを採用し、README が「権利落ち日の売りで簡単に加点」という議論を参照。目的変数が配当未調整だったために成立した加点で、経済的な利益ではない(売り方は配当相当額を支払う)。
- 効かなくなる条件: 配当調整済みリターンで採点する場合は効果が消える。寄り→引けの予測には直接効かない(ギャップは寄りで織り込み済み)。優待つき銘柄は下落幅が配当より大きくなりうる(R15)。
- 判定に必要なデータと入手時刻: 権利確定日と 1 株配当予想、営業日カレンダー。権利付き最終日は権利確定日の 2 営業日前(2019-07-18 以降)。数日前から確定している。
- 確度: B(仕組みは確実。本プロジェクトでは「採点時に配当落ちを調整する」ための注意ルールとして使う)

### R4. 米国業種 → 日本業種の翌日寄り→引けリードラグ
- IF 米国の業種 ETF の当日リターン(60 日で標準化)を日米共通の 3 成分に射影し、日本側の負荷量で戻したシグナルが上位 30% の日本業種 → THEN その業種 ETF は翌営業日の寄り→引けで相対的に上、下位 30% は相対的に下。論文の買い−売りは年率 23.79%(リスク 10.70%)。
- なぜ: 取引時間が重ならず、米国で先に織り込まれた業種共通の情報が、日本では寄り付きだけでなく日中にかけて遅れて反映される。
- 根拠: 中川ほか 2026(日米業種 ETF、2010-01〜2025-12、R/R 2.22、最大下落 9.58%、FF3 アルファ年 22.17%・t=6.69)。再現(kiwiiosaru-jp、2015-01〜2026-05、片道 2bps+借株 1.5% 控除で年率 11.99%、R/R 1.09、最大下落 28.79%)。
- 効かなくなる条件: 再現では 2024 年以降 −24%、2026-04〜05 の実運用は −17%。再現記事は米国の銘柄集中など業種構造の変化を理由に挙げている。寄り付きで全部織り込まれる日。業種 ETF は出来高が薄く、寄りと引けで気配どおりに約定できる保証がない。
- 判定に必要なデータと入手時刻: 米国業種 ETF 11 本の終値(日本時間の早朝に確定)、日本の業種 ETF 17 本の過去 60 日。朝 7 時には計算できる。
- 確度: B(単独研究+部分再現、直近は悪化)

### R5. 夜間リターンは順張り、日中リターンは逆張り
- IF 直近の夜間リターン(前日終値→当日始値)が相対的に高い → THEN 寄り→引けに対して弱い正の寄与。IF 直近の寄り→引けリターンが相対的に高い → THEN 強い負の寄与。
- なぜ: 夜間は情報(海外市場、決算)で動き、日中は需給で動くという分業があるという見方。機械が探索で見つけた重みであり、作者による機構の説明はない。
- 根拠: Morim スライドの優勝戦略(Gemini 3.1 Pro、TOPIX500、テスト 2025-01〜2026-02、順位相関 Sharpe 0.23)で夜間 +0.4、寄り→引け −0.8。2 位チーム(Gemini 3 Flash)は逆に夜間リターンも逆張りで使っており、夜間の向きはチーム間で一致していない。
- 効かなくなる条件: 夜間の向きは不安定(上記の不一致)。コスト未考慮。
- 判定に必要なデータと入手時刻: 前日までの始値・終値。当日のギャップを使うなら寄り付き後(寄り→引け予測の締切より後になるので使えない。寄り前気配で代用するなら別途データが要る)。
- 確度: C

### R6. 寄り付きギャップの大きさ(σ換算)の逆張り
- IF 寄りのギャップ ÷ 直前 20 営業日の日次リターン標準偏差(`gap_sigma`)が対象銘柄群の下位数 % → THEN 寄りで買って引けで売ると市場対比でプラス(作者は数値を意図的に非公開)。
- なぜ: 寄り付きの板寄せで売りが集中した銘柄の行き過ぎの戻り。作者は優位性が寄り付きのオークションに集中していると書いている。
- 根拠: scalplab(yfinance の日足 6 年、流動性上位約 300 銘柄、往復コスト 3〜50bp の感度分析)。初期版は当日終値を含む特徴量で先読みしており、修正版が `scripts/gap_fixed.py`。
- 効かなくなる条件: 寄り値で約定できない(ギャップが分かるのは寄った後)。寄り前気配から寄り値を当てる必要があり、作者も最大の未解決問題としている。現在の売買代金で銘柄を選んでおり生存者バイアスあり。
- 判定に必要なデータと入手時刻: 寄り前気配(8:00〜9:00、kabu ステーションなどの証券 API が必要)または寄り値(9:00 以降)。
- 確度: C

### R7. ボラティリティの持続(値幅の予測)
- IF 直近の ATR・標準偏差・高安比が高い、時価総額が小さい → THEN 今後 20 営業日の高値・安値までの変動率(値幅)が大きい。方向ではなく大きさの予測。
- なぜ: ボラティリティは自己相関が強い(北山氏の説明)。小型株は値動きが大きい。
- 根拠: SIGNATE ファンダメンタルズ分析チャレンジ(2021 年、評価期間 2021-03-27〜05-15)の 1〜3 位すべてで値幅系が最重要。UKI 氏は ATR と標準偏差の併用が効いたと回答。kashiwa350 の SHAP でも ATR(14) が最上位。
- 効かなくなる条件: 決算やイベントの直前直後(水準が跳ぶ)。値幅制限に当たる日。
- 判定に必要なデータと入手時刻: 過去 20〜120 日の四本値。前日の引け後。
- 確度: B

### R8. 決算は「数字」ではなく「事前予想との差」で動く
- IF 実績や新しい会社予想が、事前の会社予想・コンセンサスを上回る → THEN 上方向。下回れば、増収増益でも下方向。
- なぜ: 事前の期待はすでに株価に入っており、動くのは差分だけ。
- 根拠: heegle 十八手の 1 番(SIGNATE 9 位)。西村剛氏のブログ(2026-10-09)も同じ主張(統計値なし)。どちらも効果量の数値はない。
- 効かなくなる条件: 発表前に理由なく上がっていた銘柄(十八手の 3 番)。コンセンサスが取れない小型株。
- 判定に必要なデータと入手時刻: 決算短信、会社予想、可能ならコンセンサス。発表は引け後が多い。翌営業日の寄り前に判定できる。
- 確度: C(実務の経験則。学術的な決算後ドリフトは別ノートで確認が要る)

### R9. 経営者の予想の癖 → 修正方向
- IF その会社の過去数年の「(実績 − 期初予想)÷ 実績」の平均が +0.12 以上(保守的)→ THEN 期中に上方修正が出やすい。−0.12 以下(強気)→ 下方修正が出やすい。四半期進捗率が高いのに通期予想を据え置いている場合も上方修正の候補。
- なぜ: 予想の出し方は会社ごとの方針で、持続する。
- 根拠: heegle/JPX_fundamental の README(2016〜2020 年度の売上高で算出、閾値 ±0.12)。十八手の 7 番・8 番。効果量の数値はない。
- 効かなくなる条件: 経営陣の交代、会計基準や決算期の変更(十八手の 9・10 番)。
- 判定に必要なデータと入手時刻: 過去 5 年程度の決算と期初予想。いつでも計算可能。
- 確度: C

### R10. 売られ過ぎテクニカルの短期反発
- IF RSI(14) < 30、またはボリンジャーバンドの %b < 0 → THEN 3 営業日後にプラスで終わる割合が 58〜60%、平均エッジ +1.35〜+1.52%。
- なぜ: 短期の行き過ぎの戻り(R1 と同じ系統)。
- 根拠: kabu.microforge.works の方法論ページ(日経 225 採用 約 200 銘柄、2014-01〜2024-12、片道 0.1%、RSI ルール 342 取引で勝率 59.8%、%b ルール 298 取引で 58.2%)。
- 効かなくなる条件: 45 ルールを同じ期間で選び同じ期間で成績を出しており、期間外の検証ではない。同サイトの実績ページは「796 件すべてでエッジが正、平均勝率 72.6%」と表示しており、方法論ページの数値と整合しない。下落相場の継続局面。
- 判定に必要なデータと入手時刻: 過去 20 日程度の終値。前日の引け後。
- 確度: C

### R11. VIX 高水準・急騰後の短期反発
- IF VIX > 30、または VIX の 5 日変化率 > +50% → THEN 日経 225 採用銘柄は 1 週間後にプラスで終わる割合が 62.3%、平均エッジ +1.85%。
- なぜ: 恐怖による投げ売りの後の戻り。
- 根拠: R10 と同じ出典(187 取引)。
- 効かなくなる条件: R10 と同じ。発生回数が少ない。危機の初期には当てはまらない。
- 判定に必要なデータと入手時刻: VIX の終値。日本時間の早朝。
- 確度: C

### R12. 市場下落日には短期リバーサルが弱まる(条件つきルール)
- IF 当日の市場全体が下落 → THEN 直近 1 か月の負け組がさらに負ける(短期モメンタムが正方向に働く)。R1・R2 の逆張りは控える。
- なぜ: 下落日はリスク回避の売りが、直近弱い銘柄に集中する。
- 根拠: UKI いろはの「は」(2021-12、図のみで数値なし)。
- 効かなくなる条件: 不明。数値の裏付けがない。
- 判定に必要なデータと入手時刻: 市場の当日方向は事前に分からないので、寄り前の先物や米国市場で代用する。
- 確度: C

### R13. 低位株・低流動性ほど予測リターンが高く出る(警告つき)
- IF 株価の日付内順位が低い(低位株)、11 日平均出来高の順位が低い → THEN 市場中立の 2 日リターンの予測値が高い。
- なぜ: 流動性の低さに対する見返り、または売買できない価格で付いた見かけの値動き。
- 根拠: Kaggle JPX 5 位の SHAP(解説スライド)。
- 効かなくなる条件: 実際に売買しようとするとスプレッドと板の薄さで消える可能性が高い。解説者も業種・規模の偏りに注意と書いている。
- 判定に必要なデータと入手時刻: 終値と出来高。前日の引け後。
- 確度: C(予測対象から低流動性銘柄を外す根拠として使う)

### R14. 特別損失の適時開示が出た銘柄は除外
- IF 適時開示の公開項目コードに 201(特別損失)を含む → THEN 開示された週と翌週は買い候補から外す。
- なぜ: 悪材料の消化に時間がかかり、下方向のリスクが大きい。
- 根拠: J-Quants 公式チュートリアル 4.4.4 節の `get_exclude`(効果量の数値は画像のため取得できず)。
- 効かなくなる条件: 事前に織り込み済みの損失。
- 判定に必要なデータと入手時刻: TDnet の適時開示。発表は主に 15:00 以降。
- 確度: C

### R15. 権利付き最終日前後の需給と優待
- IF 権利付き最終日が近い → THEN 権利取りの買いで上がりやすく、権利落ち日に配当+優待の価値分だけ下がる。優待の金銭価値が大きいほど下落が大きい。
- なぜ: 配当・優待を取りに来る個人の買いと、その解消。
- 根拠: heegle 十八手の 12・14 番(数値なし)。
- 効かなくなる条件: 優待の価値は人によって違い、金額換算が難しい。
- 判定に必要なデータと入手時刻: 権利確定日、配当、優待内容、営業日カレンダー。事前に確定。
- 確度: C

### R16. 信用取引の投げ売りの連鎖
- IF 下落率が大きく、下落幅が日ごとに拡大している → THEN 強制決済による売りで下落が数日続く。この局面では R1・R10 の逆張りを止める。
- なぜ: 追証と強制決済が翌日以降の売りを機械的に生む。
- 根拠: heegle 十八手の 16 番(閾値・数値なし)。
- 効かなくなる条件: 閾値が示されていない。信用買い残の少ない銘柄。
- 判定に必要なデータと入手時刻: 日足、信用残(J-Quants Standard 以上、週次)。
- 確度: C

### R17. 日経平均の当日方向(朝の時点の情報から)
- IF 朝 7:20 時点の日経先物・NY ダウ・ドル円・WTI・上海総合などとの相関から計算した予想値が前日終値より高い → THEN 当日は上昇。的中率は年単位で 52〜56%。
- なぜ: 夜間の海外市場の動きが日本市場に波及する。
- 根拠: 投資の森(2024 年 128 勝 117 敗、2025 年 135 勝 108 敗、2026 年 102 勝 85 敗)。
- 効かなくなる条件: 月単位では 27〜89% と振れる。寄り付きのギャップで織り込まれた後の「寄り→引け」に対する的中率は不明(このサイトの勝敗定義は明記されていない)。
- 判定に必要なデータと入手時刻: 夜間の先物・為替・商品。朝 7 時。
- 確度: B(3 年分の公開実績。ただし定義が曖昧)

### R18. 約 1 か月の騰落率は、週次保有では順張りの方が安定(R1 と時間軸が違う)
- IF 過去約 20 営業日の上昇率が上位 → THEN 翌週(週初の寄り→週末の引け)も相対的に上。逆張りは勝率 50% で下落局面の損失が大きい。
- なぜ: 1 か月程度の値動きにはトレンドの継続がある、という単純な見方。出典は機構を説明していない。
- 根拠: J-Quants 公式チュートリアル 3.7 節(2020 年、25 銘柄、順張り勝率 60% 超・ベータ約 0.8、逆張り勝率 50%・ベータ約 1.6・3 月に約 −40%)。ニュース分析チャレンジの入賞者も短期 20 日・長期 120 日の順張りを使った。
- 効かなくなる条件: 2020 年の 1 年間だけの結果。UKI 氏は 1 か月モメンタムは全期間では負と書いており、結果が食い違う。
- 判定に必要なデータと入手時刻: 過去 20 営業日の終値。前週末の引け後。
- 確度: C

## 落とし穴・反証・注意

**検証の誤り(実例つき)**
1. **先読み**: scalplab は当日終値を含む指標で当日の寄りを判定し、現実離れした好成績を出した。修正は特徴量を 1 日ずらすこと。作者の教訓は "when a result looks too good, suspect the pipeline first"(scalplab `docs/troubleshooting.md`)。
2. **コストの片道計上**: 同じく scalplab。片道 3bp だけ引いて黒字に見えていたものが、往復にするとゼロになった。手数料が 0 円でも呼値 1 ティック分のスプレッドは払う(実効コスト = 呼値 ÷ 株価)。
3. **分割の誤り**: peisuke 氏は期間で分けるべき検証を銘柄で分けた。hajime-f のコードは銘柄ごとのスケーラーを全期間で当てており、検証期間の統計が学習に漏れている。Kaggle 2 位のコードは移動窓を銘柄ごとに区切っておらず、別銘柄の価格が混ざる。Kaggle 3 位は木の深さを学習データと重なる期間の Sharpe で選んでいる。
4. **空白期間なしの検証**: Kaggle 5 位の追試で、学習とテストの間に空白を置かないと 10 日先・20 日先の成績が不自然に良くなった。目的変数が未来の価格を含む日数ぶん空ける。
5. **同じデータでルールを選んで成績を出す**: kabu.microforge.works は「796 件すべてでエッジが正」と表示。全ルールが勝つことは通常ありえず、選別後の成績を見せている。
6. **検証期間への合わせ込み**: kiwiiosaru-jp の機械学習戦略は 1,166 回の実験で検証期間の Sharpe を 0.30 → 2.16 に上げた。検証期間が事実上の学習期間になっている。
7. **LLM の記憶による先読み**: ai-trade-check の作者は、過去期間の再生では AI が値動きを記憶している可能性を明記。

**成績の読み方**
8. Kaggle JPX の順位は運の比重が大きい。4 位は自分で「運」と書き、9 位ルールは学習期間 0.054 → 非公開期間 0.281。UKI 氏の試算では劣るモデルでも 16〜20% の確率で勝つ。
9. 特徴量や学習期間を増やすと悪化する例がある(kashiwa350)。J-Quants 公式チュートリアルも同じ注意を書いている。
10. ファンダメンタルとニュース感情は、日次〜週次の方向予測ではほとんど寄与しなかったという報告が複数ある(kashiwa350 の SHAP、Kaggle 5 位)。一方で JPX コンペ設計者は「テクニカルのみの 1.5 倍」と報告しており、時間軸と作り込みで結論が変わる。
11. 方向の上げ下げ予測に特化したモデルは満足な結果が出にくく、超短期モデルやポートフォリオ系が安定しやすい(北山氏)。成功するアイデアは 3〜4 件に 1 件、モデルが効かなくなったことの確認に半年かかることもある。
12. 銘柄コードをカテゴリで入れる効果は、SIGNATE 1 位では悪化、Kaggle 5 位では最重要と正反対。期間外の SHAP では効いていなかった。
13. 短期リバーサルは低位株・低流動性に偏る。対象を流動性のある銘柄に絞ってから検証する。

**制度・データ**
14. J-Quants Free は 12 週間遅延で当日予測には使えない。分足は別料金。無料の日本株分足はほぼない(nakanishi1337)。
15. yfinance のデータは更新時刻と信頼性が保証されず、再配布にも制約がある(Morim、yfinance-jp-screener の README)。
16. 上場廃止・売買停止・値幅制限・空売り規制を検証に入れる(UKI)。Kaggle JPX では上場廃止が原因と見られる採点エラーで約 4 割が脱落した。
17. 株式分割の調整係数は未来情報を含む(公式チュートリアル)。配当落ちを調整しないと R3 のような見かけの予測力が出る。

**ライセンス・法務**
18. J-Quants-Tutorial は CC BY-NC-ND 4.0(改変物の配布不可)、hajime-f/stocktrading は CC BY-NC 4.0、KabuForge は AGPL-3.0。heegle/JPX_fundamental と nk225-option-site はライセンス表示がない(= 既定では再利用の許諾なし)。
19. 予測を公開するなら投資助言に当たらない建て付けが要る(kashiwa350 は弁護士に相談、dexter-jp も出力の再配布で金融規制に触れうると注意)。個人で記録するだけなら関係しないが、note や X に出す場合は別途確認する。

**確認できなかったこと**
20. 商用 AI 予想サービスの公表精度は 1 件も確認できていない。「的中率 80%」のような宣伝文句を見かけても、定義・期間・件数が開示されていなければ比較対象にしない。

## このプロジェクトへの提案(MVP で採用するもの、後回しにするもの)

### MVP で採用するもの

1. **予測対象の定義を先に固定する**(北山氏の手順)。案: 東証の流動性上位銘柄(TOPIX500 相当)について、寄り→引けリターンから同日の全銘柄平均を引いた値。方向は三値(上/中立/下、閾値 ±0.5% は hajime-f の値を初期値に)。指数は日経平均の寄り→引けと前日比の両方を別々に記録する。
2. **採点器は Kaggle 9 位の `Evaluator` と MixSeek の順位相関 Sharpe の 2 本**。加えて方向的中率(件数と 95% 区間つき)。比較対象は「常に上」「前日リバーサル(R1)」「投資の森の公開予想」の 3 つ。
3. **docs ルールの初期セットは R1・R2・R4・R7・R17 の 5 本**。R3 は予測ではなく採点時の配当落ち調整として入れる。R12・R16 は R1・R2 の停止条件として書く。各ルールは kabu.microforge.works の列(名前、条件式、ホライズン、勝率、エッジ、件数)+本ノートの項目(機構、効かない条件、入手時刻、確度)で 1 行にする。
4. **機械学習の初期モデルは Kaggle 5 位を寄り→引け用に作り直す**。特徴量 8 個、`max_depth=2` の LightGBM、外れ値側だけで学習、学習とテストの間に空白、拡大窓で月次評価。そこに Morim スライドの 12 ファクターを 1 つずつ足して、台帳に効果を記録する(増やして悪化したら戻す)。
5. **記録は追記専用の SQLite**。列は投資の森の一覧(日付、予想方向、予想値、実績、当/はずれ)に、締切時刻、使ったルール ID、確信度、モデル版を足す。予測は寄り前(8:50 など固定時刻)に確定し、後から書き換えない。答え合わせは引け後の別ジョブ(jp-stock-screener の 2 段構成)。
6. **データは J-Quants Light(月 1,650 円)+公式クライアント `ClientV2`**。無料で始めるなら yfinance で代用し、更新時刻のずれを記録する。米国業種 ETF は yfinance。
7. **docs に「やってはいけないこと」を最初から書く**。上の落とし穴 1〜7 と、scalplab の Windows メモ(文字コード明示、BOM、追記型保存)。
8. **判定は日数で数える**。最初の 400 営業日相当の予測がたまるまでは「効いている/いない」を断定しない、と docs に書いておく。

### 後回しにするもの

- 分足・ティック(月 5,500 円)と寄り前気配の記録(kabu ステーションは口座と Windows 常駐が要る)。R6 の検証はここから。
- LLM に戦略を量産させる枠組み(MixSeek)。Docker 前提で、ベースラインがないと前日リバーサルしか出てこないため、MVP のルールと特徴量がそろってから。
- ニュース・適時開示のテキスト特徴量(TDnet オプションは月 11,000 円、非公式 API は可用性が不明)。日次方向への寄与が小さいという報告が多い。
- 日経 225 オプション由来の特徴量(J-Quants Standard 以上)。JPX コンペ設計者は効いたと書いているが、5 位は採用を見送っている。
- 決算ルール(R8・R9)の数値化。十八手はチェックリストとして docs に入れ、効果量は自分で測る。
- 予測の外部公開(法務の確認が先)。
