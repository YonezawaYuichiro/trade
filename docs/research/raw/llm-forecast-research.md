## 結論(5〜10 行)

1. **ニュース見出し→リターンの予測力は「初動でほぼ織り込み済み、残るドリフトは 1〜2 日・小型株・悪材料に集中」**。米国(2021-10〜2024-05、GPT-4、学習カットオフ後のみ)で、夜間ニュースのロングショート・ドリフトは 34bps/日(コスト前、ポートフォリオ日次的中率 58%)。大型株(時価総額上位 1/3)のドリフトは Sharpe 0.06・的中率 49% で実質ゼロ。往復 20bps のコストで消える。年次 Sharpe は 6.54(2021Q4)→3.68→2.33→1.22(2024/1-5)と低下。
2. **日本株の実証は存在する**。株探(Kabutan)見出し 61 万件 × TOPIX500∪日経225(2013-10〜2024-10)で、ChatGPT 見出しセンチメント(GPT-3.5 / 4o-mini)は TOPIX 並みか未満、**市場リターンで極性を付けた自作辞書**の方が明確に上(FF3 α 年率約 21%、t=2.67、片道 2.5bps コスト込み)。つまり「LLM に聞く」より「値動きで採点した単語ルール」の方が日本では強かった。これは docs ルール方式に追い風。
3. **理由つき予測+自己反省(SEP 等)は手順が公開されていて写せるが、効果量は小さい**。SEP の精度は 51〜54%、MCC 0.03〜0.10。LLMFactor の 57〜66% は評価期間(2014〜2021)が LLM の学習期間内で、先読み汚染を疑うべき数字。
4. **LLM の確率はそのままでは信用できない**。言語化した確信度は過信側、予測タスクでは 50% 寄り(ヘッジ)や「YES 寄り」も報告。対策は (a) 反対理由の列挙と過信チェックを含む scratchpad、(b) 複数サンプルの平均/刈り込み平均、(c) 自前の的中履歴での事後補正(Platt など)。推論文は予測の後付けであることが多い、という 2026 年の報告もある。
5. **先読みバイアスはプロンプトでは消せない**。「この日付以降の情報は使うな」と指示しても COVID 言及は 12.2%→6.8% に減るだけ。社名を伏せても 70% は復元される。確実なのは「モデルの知識カットオフ後のデータだけで評価する」ことで、**本プロジェクトの「毎朝予測を記録→引け後に採点」は構造的にこれを満たす**。逆に、過去データで LLM に予測させて作ったルールの成績は信用しない。
6. **LLM は数値・時系列の推論が弱い**(時系列推論はランダムをわずかに上回る程度、LLM 部分を外しても時系列予測精度は落ちない)。数値は Python で特徴量にし、LLM/人間には「大幅ギャップアップ」のような言葉のカテゴリで渡す。
7. **長期・広範囲の検証では LLM 売買戦略は buy & hold に勝てていない**(FINSABER: 20 年・S&P500 構成銘柄、StockBench: 大半のモデルが劣後)。看板論文の好成績は短期間・少数銘柄の選択的評価の産物という指摘。
8. **docs ルール方式への写し方**: 「ルールカード(IF→THEN)+ルールごとの的中スコア(HypoGeniC の UCB)+ルール保守操作(ExpeL の ADD/EDIT/UPVOTE/DOWNVOTE)+外れた予測だけ反省文(SEP)+scratchpad で確率(Halawi/ForecastBench)+Brier で採点」の組み合わせが、公開済み手法だけで組める。

## 詳細

### A. ニュース見出し→翌日リターン(必ず答えること 1)

#### A-1. Lopez-Lira & Tang(v6、2025-10)✅

- **データ**: 2021-10〜2024-05、米国普通株 4,123 銘柄、159,137 件(銘柄×見出し×日)。CRSP 日次、RavenPack 照合の見出し、TAQ 日中データ。モデルは gpt-4-0314(学習は 2021-09 まで)なので全期間がカットオフ後。
- **見出しの内訳**: 82% が夜間(取引時間外)、18% が日中。約 67.5% がプレスリリース。
- **プロンプト構造**(原文は論文参照。ここは構造のみ): 「これまでの指示を忘れ、株式推奨経験のある金融専門家として振る舞え」→「1 行目に YES / NO / UNKNOWN」→「次の行に短い 1 文で理由」→「この見出しは {社名} の短期の株価に良いか悪いか」→「Headline: {見出し}」。temperature 0。YES=+1、UNKNOWN=0、NO=−1。平均スコア 0.31、中央値 0。
- **回答の分布**(1,000 件抽出): NO 17.0% / UNKNOWN 36.6% / YES 46.4%。理由を先に書かせる版との一致率 93.5%。
- **初動(取引不能な部分)**: 夜間ニュースで YES 後 +1.27%、NO 後 −1.79%。日中ニュースで +1.33% / −3.11%。ポートフォリオ日次的中率 93.3%(夜間)/ 88.8%(日中)。回帰係数 1.326(t=31.10)。
- **ドリフト(取引可能な部分)**: 夜間ニュース→寄りで入り引けで出る戦略が平均 0.34%/日、的中率 58%、年率 Sharpe 2.97。日中ニュースは 0.50%/日、的中率 55%、Sharpe 2.63。回帰係数 0.161(t=6.80)= スコア −1→+1 で約 32bps。
- **正負の非対称**: ショート脚 26bps/日・Sharpe 2.01、ロング脚 8bps/日・Sharpe 0.78。**悪材料の方が遅く織り込まれる**。
- **サイズ別**(時価総額 3 分位、オンライン付録 OA9/OA10):

  | シグナル | サイズ | 件数 | 初動 | ドリフト |
  |---|---|---|---|---|
  | 好材料 | 小 | 17,179 | +1.99% | +0.06% |
  | 好材料 | 中 | 14,679 | +0.88% | +0.11% |
  | 好材料 | 大 | 17,953 | +0.46% | +0.05% |
  | 悪材料 | 小 | 3,819 | −2.33% | −0.70% |
  | 悪材料 | 中 | 5,080 | −1.34% | −0.18% |
  | 悪材料 | 大 | 5,452 | −1.12% | +0.06%(反転) |

  ドリフト Sharpe: 小 3.09(的中 57.85%)、中 2.09(57.91%)、**大 0.06(48.96%)**。
- **減衰**: 夜間ニュースは翌取引日 34bps、その次の日 19bps、以降有意でない。日中ニュースは当日残り 32bps、翌日 30bps。「約 2 日で吸収」。日中ニュースは発表後 1〜15 分のリターンは有意でなく(係数 0.027)、**15 分後〜引け**が有意(0.189、t=5.12)。
- **トピック別**: 決算・売上発表は初動が大きい(336.7bps)がドリフトなし(−4.7)。治験発表も初動大(308.5)・ドリフトなし。**インサイダー取引関連はドリフトあり**(26.3bps、有意)。
- **コスト**: 往復 5bps で累積 300% 超、10bps で 100% 超、**20bps で不採算**。全量日次リバランスの回転率は約 190%/日。
- **時間減衰**: 夜間戦略 Sharpe が 2021Q4 6.54 → 2022 3.68 → 2023 2.33 → 2024/1-5 1.22。close-to-close は 2024 年に有意でなくなる。著者は ChatGPT 普及(月間訪問 1.5 億→15 億超)との時期の一致を指摘するが因果検証ではない。
- **モデル比較**(ドリフト Sharpe): GPT-4 2.97、GPT-3.5 1.66、DistilBart-MNLI 1.26、BART-large 1.05、Llama2-70b 0.97、**FinBERT −0.33**、GPT-1/GPT-2/BERT は負。

### C. 理由つき予測+自己反省(必ず答えること 2)

#### C-1. SEP(Summarize-Explain-Predict)✅

**手順**

1. **Summarize**: 銘柄と当日のテキスト(原論文はツイート)→「事実の箇条書き」。few-shot 2 例。事前に BERTopic でクラスタリングし 1 日 469 件→16 件に圧縮。
2. **Explain**: 銘柄+直近 **T=5 日**分の要約→「Price Movement: Positive / Negative」+「Explanation: 1 段落」。few-shot は Positive 1 例・Negative 1 例。
3. **正誤判定**: 予測ラベルと正解の完全一致(大文字小文字無視)。Neutral / Mixed や書式違反は不正解扱い。
4. **Reflect**: **外れた時だけ**実行。入力は「前回の scratchpad(事実+予測+説明)」。出力は「外した理由の診断」と「同じ失敗を避けるための簡潔で高レベルな新方針」を数文で。
5. **再予測**: 反省文を「以前失敗した。以下の反省を使って改善せよ」というヘッダ付きで few-shot の後・事実の前に差し込み、もう一度予測。
6. scratchpad は試行ごとにリセット、反省文リストは蓄積。コード上は反復上限なし(呼び出し側が回す)。論文の分析は「3 反復後」で、方向を断定する標本が 49.8% 増、正解が 43.2% 増。
7. (写さない部分)正解/不正解ペアで報酬モデルを作り、Vicuna-7b を LoRA+PPO で微調整。推論は温度 0.7 で 4 本生成し報酬最大を採用。

**成績**(55 銘柄=11 業種×上位 5、2020〜2022、757 営業日、29,997 標本、8:2 分割)

| モデル | 業種トップ銘柄 全標本(精度 / MCC) | 同 情報あり日のみ | 残り銘柄 全標本 |
|---|---|---|---|
| GRU+Att | 50.15 / 0.0125 | – | 50.77 / 0.0189 |
| GPT-3.5 | 20.80 / 0.0094 | 29.35 / 0.0298 | 17.57 / 0.0027 |
| FinGPT | 47.61 / 0.0158 | 51.56 / 0.0384 | 45.76 / 0.0161 |
| SEP | 51.38 / 0.0302 | 54.35 / 0.0993 | 47.59 / 0.0203 |

- 素の GPT-3.5 が 20% なのは「Neutral / Mixed と答える」「書式を守らない」が不正解に数えられるため。**二択を強制する書式設計が精度に直結**する。
- ポートフォリオ(上昇予測銘柄のみ、空売りなし): Sharpe は SEP 1.150、Vicuna 1.104、GPT-3.5 0.980、Positive-Only 0.807、1/N −0.225。
- 限界: 要約→説明→予測と誤差が積み上がる。情報のない日は当て推量。説明の質は GPT-4 が採点。データはツイート 1 種。2020〜2022 は GPT-3.5 の学習期間と一部重なる。

#### C-3. 予測確率の scratchpad(Halawi et al. / ForecastBench)✅

- **Halawi のシステム**: 検索(質問の分解・拡張→記事取得→関連度採点→上位 k 件の要約)→推論(scratchpad)→統合(**刈り込み平均**。基礎モデル 3 本+微調整モデル 3 本を温度 0.5 で)。
- scratchpad の要素: 質問の言い換えと自分の知識での拡張/起きる理由・起きない理由の両方/重要度で重み付けして初期予測/過信・過小の点検と基準率の考慮/修正。
- 成績(テスト 914 問、5 プラットフォーム): Brier 0.179、群衆 0.149。精度 71.5% 対 77.0%。**群衆 4:自分 1 の加重平均で 0.146**(群衆単独を僅かに上回る)。検索なし・微調整なしだと 0.206。
- 得意不得意: 群衆が迷っている問い(0.3〜0.7)では互角(0.238 対 0.240)。群衆が確信している問いでは負ける(低い確率をほとんど出さない)。関連記事が 5 本以上ある問いでは良い。
- **ForecastBench の scratchpad 7 段**: (1) 質問を情報を落とさず言い換え、(2) NO の理由を強さ付きで列挙、(3) YES の理由を列挙、(4) superforecaster のように統合、(5) 初期確率、(6) 過信/過小でないか評価、(7) 0〜1 の最終確率。別に「できるだけ具体的な参照クラスの基準率を先に出してから調整」する superforecaster 型プロンプトがある。

#### C-4. 反省・ルール化の一般手法

- **Reflexion**✅(要旨): 重み更新なしで、フィードバックを言語で反省しエピソード記憶に保存。HumanEval pass@1 91%(当時 GPT-4 80%)。
- **ExpeL**✅: 丸パクリ表 #4 の通り。HotpotQA 39.0%(ReAct 28.0%)、ALFWorld 59.0%(40.0%)。**手書きルール 32.0%、反省文そのまま 29.0% より、学習したルールリストの方が良い**。推論時は全ルールを前提に貼り、類似の成功例を埋め込み近傍で k 件(2〜6)添える。
- **HypoGeniC**✅: 丸パクリ表 #5 の通り。見出しの人気予測で約 61%(few-shot 最良約 60%)、ツイート人気 62〜63%。**信号が弱い課題では few-shot との差は 1〜3 ポイント**という点を覚えておく。
- **FinGPT-Forecaster**✅: 丸パクリ表 #10。学習ラベルは GPT-4 の分析文で作る(=正解を知った上で「もっともらしい理由」を書かせている可能性があり、説明の因果性は保証されない)。
- **河村・久保・中川「大規模言語モデルを用いた株式投資戦略の自動生成におけるフィードバック設計」**(SIG-FIN 036、2026-03)✅(抄録): フィードバックの情報量(基本のみ/追加あり)と形式(テキスト/テキスト+図)を変えても改善効果は限定的で、**モデルの違いの方が効いた**。反省プロンプトの細部に時間を使いすぎない根拠。
- **Sarfati et al. "What LLM Forecasters Know but Don't Say"**(arXiv 2607.08046、2026-07)✅(要旨): 証拠を抜いて予測が変わっても推論文は変わらないことが多い。強制回答実験では**予測は推論を始める前にほぼ決まっている**。→ LLM の「理由」は検証対象であって根拠ではない。

- 的中率 55% と 50% を 95% 水準で区別するには約 385 件、52% と 50% なら約 2,400 件要る(二項分布の標準誤差からの自分の計算)。ルール単位の UPVOTE/DOWNVOTE を数十件で判断しない。

### E. LLM の数値・時系列推論の弱さ

- **Merrill et al. "Language Models Still Struggle to Zero-shot Reason about Time Series"**(arXiv 2404.11757)✅(要旨): 時系列の原因推定・質問応答は**ランダムをわずかに上回る程度**、人間より最大 30 ポイント低い。テキスト文脈で予測を改善する能力は「控えめ」。
- **Tan et al. "Are Language Models Actually Useful for Time Series Forecasting?"**(NeurIPS 2024 Spotlight、arXiv 2406.16964)✅(要旨): LLM ベースの時系列予測器 3 種で、LLM 部分を外すか単純な attention 層に替えても精度は落ちず、むしろ改善することが多い。事前学習の利得なし、few-shot でも利得なし。
- **StockTime**(arXiv 2409.08281)❓(検索要約のみ): LLM 本体を凍結し時系列埋め込み層だけ学習する株価専用アーキテクチャ。公式コード未発見。E の 2 本を踏まえると優先度は低い。
- **Yu et al. "Temporal Data Meets LLM"**(arXiv 2306.11025)✅(要旨): NASDAQ-100 で GPT-4 のゼロ/few-shot と Open LLaMA 微調整。ARMA-GARCH や勾配ブースティングを上回ると主張するが、数値・期間は要旨に無い。
- **設計への含意**: SEP の「GPT-3.5 精度 20%」、LLMFactor の「値動きを文章にして渡す」、FinGPT-Forecaster の「騰落をビンで表す」は全て同じ教訓=**LLM に生の数値列を読ませない・計算させない**。

### G. docs ルール方式に写せる設計(必ず答えること 5)

以下は上の文献の部品を組み合わせた**本プロジェクト向けの設計案**(自分の提案。文献がこの組み合わせで検証したわけではない)。

#### G-1. ルールカードの書式(1 ルール 1 ファイル、または 1 節)

```
id: R-NEWS-NEG-SMALL-01
IF: (観測条件を機械判定できる形で。例: 前日15:30〜当日8:50に悪材料見出し AND 時価総額が下位1/3)
THEN: 方向=下 / 目安=寄り→引け −0.3〜−0.7% / 時間軸=当日
WHY: (メカニズム 1〜3 文)
EVIDENCE: (出典URL・市場・期間・効果量)
INVALID_IF: (効かなくなる条件)
DATA: (判定に必要なデータと入手時刻)
GRADE: A / B / C
weight: 2        # ExpeL 式。新規は 2
n_fired: 0       # 発火回数
n_hit: 0         # 的中回数
ucb: null        # 的中率 + α·sqrt(log t / n_fired)
status: candidate / active / retired
```

- IF は**LLM の主観なしで判定できる**ことを原則にする(単語の有無、数値の閾値、時刻)。こうすると過去データへの当てはめが LLM なしでできるので、B 節の先読み問題を回避できる。CIRJE 論文の辞書が ChatGPT に勝った構図と同じ。
- LLM の主観判定が要る条件(「好材料か」)は、A-1 の YES/NO/UNKNOWN で 1 段挟み、**その LLM 出力をカットオフ後の実運用でだけ採点**する。

#### G-2. 毎朝の予測手順(人間でも LLM でも同じ紙で実行)

1. **事実の要約**(SEP の Summarize): 対象銘柄ごとに、前日引け後〜当日朝の適時開示タイトル・見出しを箇条書き。意見や値動きの解説文は入れない。
2. **要因抽出**(LLMFactor): 株価に効きそうな要因を最大 5 個。
3. **ニュース採点**(CausalStock の 5 軸): 関連度 0〜10 / センチメント −1〜1 / 重要度 0〜10 / 株価影響 0〜10 / 持続 0〜10。数値のみ。
4. **数値特徴は Python が言葉にして渡す**(LLMFactor / FinGPT 方式): 「直近 5 日: 上昇・下落・上昇・上昇・下落」「寄り前気配: 大幅ギャップアップ(+3% 以上)」「出来高: 20 日平均の 2 倍超」など。生の数値列は渡さない。
5. **ルール照合**: 発火したルールカードの id を列挙。発火なしなら「該当ルールなし→基準率」。
6. **確率の scratchpad**(ForecastBench 7 段+基準率): 基準率(その銘柄群の寄り→引け上昇率を自前データから)→下がる理由→上がる理由→統合→初期確率→過信/過小チェック→最終確率。
7. **出力**(二択を強制。SEP の教訓): `{"code": "XXXX", "direction": "UP|DOWN", "p_up": 0.xx, "bin": "U1|D1|…", "fired_rules": [...], "reason": "1 段落"}`。Neutral は禁止し、迷う場合は p_up を 0.5 近くにする。
8. LLM を使う場合は**同じ入力で 3〜8 本生成し刈り込み平均**(Halawi は 6 本、xAI は 8 本)。
9. 予測は寄り付き前に追記専用ファイルへ保存(タイムスタンプ付き)。

**見出し採点プロンプトの日本語化案**(構造は A-1 を踏襲、文言は自作)

```
あなたは日本株の短期売買の経験がある金融の専門家として答える。
次の見出しは、{社名}({コード})の「当日の寄り付きから大引けまで」の株価にとって良い材料か、悪い材料か。
1 行目に YES(良い)/ NO(悪い)/ UNKNOWN(判断できない)のどれか 1 語だけを書く。
2 行目に理由を 1 文で書く。
見出し: {見出し}
```

- A/B 用に `{社名}` を「A 社」に、見出し中の社名・製品名をダミー語に置換した匿名版も同時に取る(Glasserman & Lin)。
- temperature 0。YES=+1 / UNKNOWN=0 / NO=−1。

**予測+説明プロンプトの構造**(SEP の Explain を踏襲、文言は自作)

```
[役割] 以下の事実だけから、{コード} の当日寄り→引けの値動きを推定する。
[過去の反省] (あれば)以前この種の予測で外した。次の反省を必ず踏まえる: …
[発火ルール] R-…: IF … THEN …(的中 n_hit/n_fired)
[事実] ・… ・…
[値動きの言葉] 直近5日: …/ 寄り前気配: …
[出力] Price Movement: Positive か Negative のどちらか 1 語
       Explanation: 1 段落(どの事実・どのルールを根拠にしたか)
```

**反省プロンプトの構造**(SEP の Reflect を踏襲、文言は自作)

```
前回、{コード} について以下の事実から値動きを予測し、外した。
[前回の入力と出力をそのまま貼る]
[実際の結果] 寄り→引け {±x.x%}
外した理由として最もありそうなものを 1 つ診断し、同じ失敗を避けるための短い高レベルの方針を書く。数文、完全な文で。
```

#### G-3. 引け後の採点と反省

1. ラベル: sign(引け/寄り − 1)。同時に対 TOPIX 超過の符号も記録(CIRJE の「市場プレミアム」の方が辞書の質が上がった)。
2. 指標: 的中率、Brier (p−o)²、対数損失。基準として「常に 0.5」「常に基準率」「前日と同方向」「何もしない(buy & hold)」を毎日同じ表に並べる(FINSABER の教訓)。
3. **反省は外れた予測だけ**(SEP)。かつ確信度が高かった外れを優先。反省文は銘柄別ではなくルール id に紐づけて保存。
4. 発火ルールごとに n_fired / n_hit を更新し UCB を再計算(HypoGeniC)。

#### G-4. 週次のルール保守(ExpeL+HypoGeniC)

1. 入力: その週の「外れ/当たりのペア」(同じルールが発火して結果が分かれた例)と「当たり 4〜8 件の束」。
2. 操作は 4 つだけ: **ADD**(新ルール、weight=2、status=candidate)/ **EDIT**(条件の絞り込み。weight+1)/ **UPVOTE**(+1)/ **DOWNVOTE**(−1)。weight が 0 になったら retired。
3. どのルールでも説明できなかった外れを「wrong example bank」に貯め、**10 件**で新ルール候補の生成を起動。active は上位 20 本まで。
4. **昇格条件(自分の提案)**: candidate→active は発火 100 回以上かつ基準率を上回る、GRADE の引き上げは 400 回以上(D 節の標本数計算)。数十件での判断を禁止。
5. 新ルール候補は必ず「機械判定できる IF」に書き直してから過去データ(LLM を通さない)で当てはめ、その結果も EVIDENCE に書く。

#### G-5. 月次の較正

1. 予測者ごと(ML / ルール人間 / ルール LLM)に、p_up を 5 ビンに分けた信頼性表(予測平均 vs 実現頻度)を docs に出力。
2. 解決済み予測が 300 件を超えたら、logit(p) に対するロジスティック回帰(Platt)を**直近窓で**当て、補正後の Brier が未補正を下回る時だけ採用(Halawi は binning / isotonic で改善しなかったので、効かなければ使わない)。
3. それまでは基準率への縮小 p' = base + 0.5·(p − base) を既定に(自分の提案。文献の式ではない)。
4. 匿名版と原見出し版の成績差(distraction)を銘柄サイズ別に集計。

#### G-6. LLM の暗記チェック(モデルを替えるたびに 1 回)

- 文脈なしで「{日付} の日経平均終値は?」「{社名} の {決算期} の連結売上高は?」を、カットオフ前 30 問・後 30 問。前だけ異常に当たるなら、そのモデルで過去日付の予測実験をしない(B-2、EDINET DB ブログの方式)。

## 因果ルール候補

確度の付け方: A=複数の査読研究で再現 / B=単独研究や実務統計あり / C=経験則・未検証。**米国の結果を日本に当てる場合は 1 段下げている**。

### R-01 寄り→引けの無条件期待値は負(夜間に上がり日中は上がらない)

- IF: TOPIX500∪日経225 の銘柄で、特段の材料がない日 → THEN: 寄り→引けの期待リターンはゼロ〜やや負。目安は年率 −5.0%(1 日あたり約 −2bps)。時間軸は当日。
- なぜ: 上昇分が引け→寄り(夜間)に集中する現象。メカニズムは本調査では未確認(別観点で要調査)。
- 根拠: https://www.cirje.e.u-tokyo.ac.jp/research/dp/2026/2026cf1267.pdf Table 2。日本、2013-10-01〜2024-10-18、631 社。open-to-close 年率 −5.0%、close-to-close +12.4%。
- 効かなくなる条件: 2024-11-05 の取引時間延長以降は標本外。平均が負でも上昇日の比率が 50% 未満とは限らない(比率は自前データで要計算)。
- 判定に必要なデータと入手時刻: 日足の始値・終値。前日まで分で足りる。
- 確度: B

### R-02 小型株の夜間の悪材料は寄り後も下げ続ける

- IF: 前日引け後〜当日寄り前に悪材料の見出し(LLM 判定 NO)AND 時価総額が下位 1/3 → THEN: 寄り→引けで下。目安 −0.7%(米国の値)。時間軸は当日、翌日も弱い。
- なぜ: 小型株は注目する投資家が少なく、空売り制約もあり、悪材料の織り込みが遅い(注意の制約と裁定の限界)。
- 根拠: https://arxiv.org/abs/2304.07619 付録 OA9。米国、2021-10〜2024-05、悪材料×小型 3,819 件、初動 −2.33%、ドリフト −0.70%。小型のドリフト Sharpe 3.09、的中 57.85%。Heston & Sinha も悪材料の遅延反応を報告。
- 効かなくなる条件: 大型株(R-03)。コスト往復 20bps 超。LLM 普及で年々縮小(R-11)。決算・治験のような「一発で織り込む」材料(R-05)。日本では悪材料側が弱いという結果あり(R-07)。
- 判定に必要なデータと入手時刻: TDnet・ニュース見出し(前日 15:30〜当日 8:50)、時価総額(前日)。
- 確度: B(米国)。日本株への適用は C。

### R-03 大型株は夜間ニュースの方向へのドリフトがない

- IF: 時価総額上位 1/3 の銘柄に夜間ニュース(好悪問わず)→ THEN: 寄り→引けの方向は基準率どおり(優位性なし)。悪材料ではむしろ小幅反発(+0.06%)。
- なぜ: 注目度が高く寄り付きまでに織り込まれる。
- 根拠: 同上。大型のドリフト Sharpe 0.06、的中率 48.96%。Glasserman & Lin でも大型株ほど LLM の思い込みが害。
- 効かなくなる条件: 引け後でなく場中に出たニュース(R-04)。
- 判定に必要なデータと入手時刻: 同上。
- 確度: B

### R-04 場中ニュースは最初の 15 分ではなく、その後〜引けに効く

- IF: 取引時間中に個別材料の見出し → THEN: 発表 15 分後〜当日引けまで材料の方向に動く。目安はスコア −1→+1 で約 38bps(係数 0.189×2)。翌日も同程度続く。
- なぜ: 初動は即時だが、注意の遅れで残りが引けまでにじわじわ入る。
- 根拠: https://arxiv.org/abs/2304.07619 Table 3。1〜15 分の係数 0.027(有意でない)、15 分〜引け 0.189(t=5.12)、close-to-close 0.116(t=2.31)。
- 効かなくなる条件: 大型株、コスト。寄り前に予測を固定する運用では使えない(場中に予測を更新する枠が要る)。
- 判定に必要なデータと入手時刻: 場中の見出しと時刻、5 分足。リアルタイム。
- 確度: B(米国)。日本は C。

### R-05 決算・売上の見出しは初動で織り込まれ、寄り後の追随は期待できない

- IF: 夜間の材料が決算・業績数値そのもの → THEN: 寄りのギャップは大きいが、寄り→引けの方向は基準率どおり。
- なぜ: 決算は最も注目される予定イベントで、寄り付きの板寄せで価格発見が済む。
- 根拠: Lopez-Lira & Tang のトピック別(決算・売上: 初動 336.7bps、ドリフト −4.7bps)。日本: 種村ほか LLM-PEAD.txt(https://doi.org/10.11517/jsaisigtwo.2025.FIN-035_157)で SUE 単独・LES 単独とも一貫した PEAD なし。
- 効かなくなる条件: R-06 の組み合わせ条件。
- 判定に必要なデータと入手時刻: 決算短信(TDnet、前日 15:30 以降)。
- 確度: B

### R-06 数値は良いが文章が弱い決算でだけ、サプライズ方向のドリフトが出る

- IF: 決算で数値サプライズ(SUE)が高い AND LLM が読んだテキストのサプライズ(LES)が低い → THEN: 決算後、サプライズ符号と整合する方向にドリフト。大きさ・期間は本文未確認。
- なぜ: (著者の示唆)LLM が拾う文脈情報は数値や辞書極性と独立の情報を持つ。組み合わせで初めて未織り込み部分が現れる。
- 根拠: 同上(日本株、決算短信)。抄録レベル。
- 効かなくなる条件: 抄録のみで数値未確認。単独研究。
- 判定に必要なデータと入手時刻: 決算短信の数値と本文、過去の SUE 計算用データ。
- 確度: C

### R-07 日本では好材料キーワードの見出しの方が翌日に効く

- IF: 当日 0:00〜14:57(現行は 15:27)に、値動きで極性づけした辞書でスコア>0 の見出し → THEN: 当日引け→翌日引けで上。目安 +0.28%(ベースライン +0.05%)。スコア<0 なら −0.14%。
- なぜ: 見出しの情報が当日中に織り込み切れない。日本語見出しは悪材料を婉曲に書くので単語では拾いにくい(著者の仮説)。
- 根拠: CIRJE-F-1267 Table 9。日本、検証 2016-04〜2024-10、好材料 t=8.30、悪材料 t=−5.71。戦略は片道 2.5bps 込みで FF3 α 年率 21.31%(t=2.67)。
- 効かなくなる条件: 寄り→引けではなく**引け→翌引け**の規約なので、当プロジェクトの主対象とは時間軸がずれる(夜間と日中の内訳は未検証)。辞書に「急反発」「年初来高値」など値動き語が入っておりモメンタムの可能性。株探の利用規約(機械取得の可否)は未確認。
- 判定に必要なデータと入手時刻: 株探等の見出しと時刻(当日 15:27 まで)、辞書(年次更新)。
- 確度: B

### R-08 日次ニュースの予測力は 1〜2 日で消える

- IF: 材料が出てから 3 営業日以上経過 → THEN: その材料を理由にした方向予測はしない(基準率に戻す)。
- なぜ: 情報は約 2 日で価格に吸収される。
- 根拠: Lopez-Lira & Tang(夜間ニュース: 翌日 34bps、翌々日 19bps、以降有意でない)。Heston & Sinha(2003〜2010、日次ニュースは 1〜2 日)。2 研究で一致。
- 効かなくなる条件: 週次に集計したニュース量・トーンは 13 週効く(Heston & Sinha)。悪材料は次の決算発表周辺まで遅れて効く。
- 判定に必要なデータと入手時刻: 材料の初出日時。
- 確度: A(米国で 2 研究一致)。日本は B。

### R-09 インサイダー取引・大株主関連の開示は遅れて効く

- IF: 役員・大株主の売買に関する見出し → THEN: 開示の方向(買い=上、売り=下)に翌日以降もドリフト。目安 26.3bps(米国)。
- なぜ: 決算と違い注目されにくく、過小反応が残る。
- 根拠: Lopez-Lira & Tang のトピック別(Insider stock transactions のドリフト整合 26.3bps、有意)。
- 効かなくなる条件: 日本の大量保有報告書・自己株買い開示に当てはまるかは未検証(SIG-FIN 037 に「大量保有報告書の提出イベントと株式リターンに関する実証分析」あり、未読)。
- 判定に必要なデータと入手時刻: EDINET 大量保有報告書、TDnet 自己株取得。
- 確度: C(日本)

### R-10 適時開示のタイトルの種類だけで短期急落リスクが少し分かる

- IF: 開示タイトルが過去に急落を伴った類型に近い(埋め込み近傍)→ THEN: 開示日〜+3 営業日の累積異常リターンが下位 5% に入る確率が上がる。
- なぜ: タイトルの定型(下方修正、特別損失、第三者割当など)が内容の代理変数になる。
- 根拠: 伊藤(2025)https://doi.org/10.11517/jsaisigtwo.2025.FIN-035_68 。TDnet 約 69 万件、2020-04〜2025-04。F1 0.235→0.265、PR-AUC 0.164→0.192。
- 効かなくなる条件: 改善幅は小さい。方向ではなく「急落の裾」の判別。寄り→引けでなく 3 日 CAR。
- 判定に必要なデータと入手時刻: TDnet タイトル(公開時刻)。
- 確度: B(単独研究)

### R-11 LLM が読める材料の優位性は年々縮む

- IF: ルールの根拠が「LLM で見出しを読めば分かる」類 → THEN: 文献の効果量を当年はさらに割り引く。目安は 2021Q4→2024 前半で Sharpe が約 1/5。
- なぜ: 同じことをする参加者が増え、価格が速く効率化する。
- 根拠: Lopez-Lira & Tang(6.54→3.68→2.33→1.22)。時期の相関であり因果検証ではない。
- 効かなくなる条件: LLM が読みにくい日本語の小型株・図表だけの開示(JFinSR では要因情報 219 例のうち約半分の 105 例がテキストのみで、残りは図表を含む)。
- 判定に必要なデータと入手時刻: なし(メタルール)。
- 確度: B

### R-12 値上がり/値下がり率上位の大半は、当日か前日の会社発表で説明がつく

- IF: 前日夕方〜当日朝に会社の公開情報(適時開示・プレスリリース)がある → THEN: その銘柄が当日の値動き上位に入る確率が上がる(方向は内容次第)。
- なぜ: 大きな値動きの原因は新情報であり、その多くは会社自身の発表。
- 根拠: 西田・宇津呂 JFinSR(ANLP 2025)。株探記事つき 287 例中、会社公開情報と同内容 219 例、うち同日公開 112・1 日前 75・2 日以上前 32。
- 効かなくなる条件: 12 営業日・1,200 例の小標本。PDF 抽出が一部文字化けで、表の解釈は原典で要再確認。68 例はレーティング等、他者発の情報。
- 判定に必要なデータと入手時刻: TDnet・企業サイトの発表(前日 15:30〜当日)。
- 確度: C

### R-13 大型株から同業小型株へ影響が流れる

- IF: 業種の大型株に大きな材料・値動き → THEN: 同業の小型株が同方向に遅れて動く。大きさ・ラグは未確認(モデルのラグ設定は 5 日)。
- なぜ: 小型株は情報の織り込みが遅く、大型株の動きが先行指標になる。
- 根拠: CausalStock(NeurIPS 2024)。NI225 データで因果強度と時価総額の Spearman 相関 0.7212(p=0.0185)。
- 効かなくなる条件: 売買検証ではなくモデルの解釈結果。日本データは 51 銘柄・価格のみ・2016-07〜2019-12。
- 判定に必要なデータと入手時刻: 業種分類、前日の大型株の値動き。
- 確度: C

### R-14 有報の文章が明るすぎる会社は、その後 1 年は相対的に弱い

- IF: 有報 MD&A の LLM センチメントが上位 20% → THEN: 7 月〜翌 6 月の 1 年で下位 20% に対し劣後。目安は α 年率 −6〜−9%。
- なぜ: 楽観的な開示への初期の過大評価が後で修正される(著者の解釈)。
- 根拠: Okada et al.(PeerJ CS 2025 / ANLP 2025 E5-2)。東証、2014〜2023、GPT-4 FF3 α −5.95%(5% 有意)、Claude −9.15%(1% 有意)。Gemini・辞書・DeBERTaV2 は有意でない。
- 効かなくなる条件: 日中予測には時間軸が合わない(銘柄の長期バイアスとして使う程度)。2014〜2023 は使用 LLM の学習期間内(先読みの可能性。ただし符号が直感と逆なので単純な暗記では説明しにくい)。モデル依存が大きい。
- 判定に必要なデータと入手時刻: EDINET 有報(6 月末)。
- 確度: B(年次の時間軸)。日中予測への利用は C。

### R-15 指数全体には好材料の方が効き、悪材料は予測力がない

- IF: 主要紙の記事から抽出した「良いニュース」の比率が高い → THEN: 市場全体の先行きリターンが高い。景気後退期・不確実性が高い時に強い。
- なぜ: 市場全体では好材料への過小反応が残る。
- 根拠: Chen, Tang, Zhou, Zhu(arXiv 2502.10008)。米国、WSJ。予測の時間軸・期間は要旨に記載なし。
- 効かなくなる条件: 個別株(R-02 と正負が逆)。ChatGPT 以外のモデルでは再現せずと著者自身が報告=頑健性に疑問。
- 判定に必要なデータと入手時刻: 日経等の記事。
- 確度: C

## 落とし穴・反証・注意

1. **看板論文の数字はコスト前**。Lopez-Lira & Tang の夜間戦略は回転率 約 190%/日、往復 20bps で不採算。我々は発注しないが、「当たった」の閾値を 0 ではなくコスト相当(CIRJE は 15bps)に置いた採点も併記すべき。
2. **学習期間内の検証は全て割り引く**。LLMFactor(2014〜2021)、SEP(2020〜2022)、Kirtac & Germano(2010〜2023)、Okada et al.(2014〜2023)、CIRJE の ChatGPT 比較(2016〜2024)は、使ったモデルの学習期間と重なる。DatedGPT は先読みの上乗せを 26.4bp/標準偏差と測った。
3. **「未来の情報は使うな」は効かない**(Sarkar & Vafa、Lopez-Lira et al.)。匿名化も大型株では破られる。ただし匿名化は distraction の除去として有益な場合がある(Glasserman & Lin)。
4. **説明文は後付けの可能性**(arXiv 2607.08046)。「理由つき予測」の理由を因果知識として docs に写す時は、必ず機械判定できる IF に直して別途検証する。FinGPT-Forecaster の学習用説明文は GPT-4 に作らせたもの。
5. **素の LLM は二択を守らない**。SEP では GPT-3.5 が Neutral / Mixed を多発し精度 20%。Lopez-Lira でも UNKNOWN が 36.6%。「UNKNOWN の日は予測しない」のか「0.5 として採点する」のかを最初に決める。
6. **FinBERT は用途で評価が割れる**。Lopez-Lira ではドリフト Sharpe −0.33、Kirtac では 2.07、ChronoBERT 論文の埋め込み利用では 3.86。分類ラベルとして使うか、埋め込みを回帰に入れるかで違う。
7. **汎用の極性辞書はリターンに直結しない**(CIRJE: 外部辞書 BoW は α 有意に負、Okada: 辞書は有意でない)。極性は「値動きで付け直す」。
8. **日米で正負の非対称が逆**。米国個別株は悪材料が遅い(Lopez-Lira、Heston & Sinha)、日本の株探見出しは好材料が強い(CIRJE)、米国指数は好材料のみ(Chen et al.)。**米国ルールを符号ごと日本に写さない**。SIG-FIN 035 には日本でニュースタイトル・センチメントの「短期リバーサル」を使う発表もある(未読)。
9. **取り下げ・後退した論文がある**。Kim, Muhn, Nikolaev は arXiv で取り下げ。MemGuard-Alpha は v2 で「濾過は効かない」に後退。二次記事の数字は版を確認する。
10. **ニュース検索を足しても確率予測は良くならなかった**(ForecastBench 2024)。情報を足すより、基準率と群衆(市場)値に寄せる方が効いた。株なら「寄り前気配・先物」という市場の集約値を必ず入力に入れる。
11. **反省プロンプトの細部は効果が小さい**(河村ほか 2026)。モデル選択の方が効く。
12. **標本数**。ルール 1 本の良し悪しは数百回の発火がないと分からない(D 節)。ExpeL / HypoGeniC は信号の強い課題(的中 60〜75%)で検証された手法で、信号の弱い株の騰落にそのまま当てるとノイズでルールが入れ替わり続ける恐れがある。
13. **LLM エージェントは長期では buy & hold に負ける**(FINSABER、StockBench)。強気相場で慎重すぎ、弱気相場で攻めすぎる癖も報告。
14. **ライセンス**。koa-fin/sep、dannyallover/llm_forecasting、benstaf/lookaheadbench、HKUDS/AI-Trader は GitHub API 上ライセンス表記なし=コードの複製・改変は許諾なしと扱う。構造を読んで再実装する。CIRJE ディスカッションペーパーは著者の同意なき転載・配布不可の注記あり(数値・手法の要約は可)。
15. **データ取得の規約**。株探・日経の見出しを機械取得してよいかは本調査で未確認。TDnet・EDINET を一次情報にする方が安全。
16. **2024-11-05 の東証取引時間延長**(15:00→15:30)。CIRJE の標本は延長前まで。開示が集中する時刻・引けの値決めが変わっており、「14:57 規約」「引け後ニュースは翌日終値に効かない」は現行制度で再検証が要る。
17. **本ノートの数値は要約モデル経由**。Halawi の RMS 較正誤差(.42/.38)のように桁が怪しいものがある。正本化の前に原典で確認。

## このプロジェクトへの提案

### MVP で採用するもの

1. **採点表の骨格**: 予測は寄り前に追記専用で保存し、引け後に Brier・的中率・対数損失を計算。基準行として「常に 0.5」「常に基準率」「前日と同方向」を必ず並べる。対 TOPIX 超過の符号も記録。
2. **ルールカード書式(G-1)と R-01〜R-15 の初期登録**。全て status=candidate、weight=2 で開始。
3. **見出し採点(G-2 の日本語化プロンプト)**を TDnet タイトルと見出しに適用。YES/NO/UNKNOWN と理由 1 文を保存。匿名版も同時に取り A/B。
4. **数値は Python で言葉に変換**してから LLM/人間に渡す(直近 5 日の上げ下げ、ギャップ区分、出来高区分)。
5. **scratchpad 7 段+基準率**で p_up を出す。LLM は 3 本生成して中央値(コストが許せば 6〜8 本の刈り込み平均)。
6. **反省は外れた予測だけ**。反省文はルール id に紐づけて保存。
7. **サイズ区分を全予測に付ける**(時価総額 3 分位)。R-02 / R-03 の検証がそのままできる。
8. **LLM の暗記チェック(G-6)**を採用モデルで 1 回やり docs に記録。
9. **「値動きで極性を付ける辞書」の日本版**(CIRJE 方式)を、まず TDnet タイトルの単語で小さく作る(閾値 15bps、上位 100 語、年次更新)。これは ML 側とルール側の両方の入力になる。

### 後回しにするもの

1. SEP の PPO 微調整、FinGPT の LoRA(GPU とコストが要る。効果量も小さい)。
2. ChronoGPT / DatedGPT による過去検証(英語モデル。日本語見出しに使えない)。
3. CausalStock 型の銘柄間因果グラフ学習(コードなし。R-13 は単純な「前日の同業大型株の騰落」特徴で代用)。
4. HypoGeniC の自動仮説生成の全自動化(まず手動の週次レビューで回し、発火数が溜まってから)。
5. Platt 補正(解決済み 300 件超から)。
6. 有報センチメント(R-14)の年次特徴。
7. 経済因果チェーン検索からのルール種の大量収集(サービスの安定性と利用条件が不明)。
8. 場中ニュースでの予測更新(R-04)。寄り前固定の運用が安定してから。
