## 無菌室とは何か

無菌室とは、過去データから「一番儲かった設定」を拾えないようにした手順です。過去データは次の4つにだけ使います。

- 優位性のない方法を捨てる
- 悪いときにいくら失いうるかを知る
- 手数料と滑りを見積もる
- 繰り返し現れる市場の性質を記録する

全期間で最も儲かったパラメータは、採用の理由にしません。優位性がまったくない規則でも、短期間に何度も試せば、最良のものは良く見えます。実験Bは、その縮小版です。

言ってよい結論は、次の3つだけです。

- 未検証。門が1つでも残っている。
- 不採用。門に落ちた。
- 未確認。過去データでは門を通ったが、事前登録より後のペーパーがまだ終わっていない。

「儲かった」「優位性がある」「実弾で使える」は、3つ目のペーパーで、費用を引いた差が残るまで書きません。税を引く前の数値を、手取りの利益と書かないでください。授業のテスト精度が高いことは、この3つのどれでもありません。

規則は結果を見てから緩めません。迷ったら、試行を増やさない側、新しい建玉を持たない側に倒してください。

## 室の規則

1. 事前登録が先です。仮説、分割、判定基準、コスト、試行回数の上限を、収益率を計算する前にファイルへ書き、ハッシュを残します。書いた後に基準を変えるなら、その実験は破棄し、新しい実験として登録し直します。

    近い実験（本人）: A

2. 試したものはすべて数えます。捨てた設定、近くのパラメータ、特徴量を足した回数、銘柄の選び直し、期間の切り直し、乱数の種の選び直し、検証期間を見て閾値を変えた回数、クラスで一番良かった人を選ぶこと。銘柄を横断して一番良い規則を選ぶとき、試行回数は銘柄数×規則数です。採用しなかった案も1回です。

    近い実験（本人）: B

3. 選ぶ基準は頑健性です。期間を分けた成績の中央値、最も悪い期間、パラメータを少し動かしたときの安定性。全期間の利益の最大値では選びません。

    近い実験（本人）: B

4. データは使うと減ります。取得できた期間の末尾はホールドアウトとしてロックします。長さは収益率を見る前に固定します。目安は末尾6か月です。取得できた期間がそれより短ければ、短い側の長さを理由とともに固定します。ロック期間は専用の手順で1回だけ開きます。開いた後に設定を変えたら、新しい実験です。

    近い実験（本人）: A

5. この約2年の値動きは、私とあなたがニュースとしてすでに知っている可能性があります。過去のホールドアウトは、最終合格にしません。最終判定に使えるのは、仮説と規則と閾値をファイルに書いてハッシュを残した時刻より後に起きた値動きだけです。予測は、その営業日の値動きを知る前にファイルへ書きます。書いてから、データが届いて採点します。ニュース、証券アプリ、会話で見た値動きを、未知のデータとして扱わないでください。

    近い実験（本人）: A

6. 各時点で、その時点に存在した情報だけを使います。特徴量は、その足が確定した時刻以降にだけ計算します。末尾を切り詰めて再計算しても過去の値が変わらないこと、開始点をずらしても一定期間後に一致することを、合成データで自動テストにします。このテストが落ちる特徴量は使いません。実験A1が、この条の実物です。

    近い実験（本人）: A

7. 学習、検証、ホールドアウトは時系列で分けます。行を混ぜた交差検証は使いません。ラベルが先の期間と重なるときは、重なる部分を学習から除き、その後ろにラベルの期間以上の余白を置きます。ラベルが見ている期間と、建玉を持つ期間は一致させます。検証期間で閾値や特徴量を選び直したら、その検証は学習に降格し、選び直しは試行に数えます。実験A2が、この条の実物です。

    近い実験（本人）: A

8. 機械学習の実装では、次を守ります。時系列をシャッフルして分けない。標準化、欠損の埋め、特徴量の選択、主成分分析は、各学習窓の中だけで適合する。中央寄せの移動窓を使わない。全期間の重要度を見て特徴量を捨てない。ラベルは未来を使ってよい。特徴量は未来を使ってはいけない。

    近い実験（本人）: A

9. 約定は、シグナルに使った足の値段では行いません。日足の高値、安値、終値は、そのセッションが終わるまで未知です。その日の高値や安値で売買できたことにしないでください。既定の約定は、翌営業日の始値の成行です。引けで約定させる規則は、引け注文を出せた時刻と、その日の終値をシグナルに使っていないことの両方を、収益率を見る前に書いたときだけ使います。

    近い実験（本人）: C

10. 日足には板の待ち行列がありません。指値がその日の安値以下、高値以上に触れただけで約定したことにしないでください。日足だけの研究で、合格判定に使ってよい約定は成行だけです。逆指値は、翌営業日の始値が逆指値を飛び越えていたら、逆指値ではなく、その始値で約定します。

    近い実験（本人）: C

11. 四本値が Null の日は、約定もリターンもありません。前日の終値を繰り越して埋めないでください。値幅制限に当たった側への成行を、制限値段で必ず約定したことにしないでください。仕様で約定不能と分かる日は、約定しません。

    近い実験（本人）: C

12. 往復コストの下限は0円にしません。証券会社の手数料が0円でも、スプレッドと滑りは残ります。無料データにスプレッドはありません。下限は、その約定日に有効な呼値を公式の表で引き、往復で呼値2つ分を値段で割ったもの以上にします。呼値の表は改定されるので、表の数値を記憶で書かないでください。公式は https://www.jpx.co.jp/equities/trading/domestic/07.html です。コスト2倍の検査は、この下限をさらに2倍して行います。下限をより小さくするときは、自分で測った板の記録と、私の確認が先です。

    近い実験（本人）: C

13. 数量は単元の整数倍だけです。内国株の売買単位は、公式の説明では100株です。確認は https://www.jpx.co.jp/equities/trading/domestic/03.html で、私の画面を正とします。ETFなど、単位を公式で一文にできない商品は取引対象から外します。端株を買えたことにしないでください。

    近い実験（本人）: C

14. 空売り、信用取引、レバレッジは使いません。貸株料と金利が、この無料データにありません。現物で、初期資金の範囲だけを使います。

    近い実験（本人）: C

15. 比べる相手は、同じ費用、同じ期間、同じ初期資金で動かす次の6つです。パラメータは、収益率を見る前に固定します。この回では名前だけを書きます。
    - ユニバースの等ウェイトの単純保有
    - 戦略と同じ平均建玉の、固定した保有。主の相手はこれです
    - 予測したボラティリティで建玉を増減するもの
    - ボラティリティが高いときだけ建玉を減らすフィルター
    - トレンドのフィルター
    - 同じ平均建玉、同じ回転率で、無作為に持つもの
    主の相手との建玉の差がほぼゼロなら、その実験は「違いが測れなかった」です。勝ったことにはしません。

    近い実験（本人）: C

16. 合格判定に、平均÷標準偏差×√252 は使いません。建玉が複数日にまたがると、日次の収益率は独立ではありません。独立とみなした年率化は過大になります。出典は Lo, "The Statistics of Sharpe Ratios," Financial Analysts Journal, 2002. https://doi.org/10.2469/faj.v58.n4.2453 です。年率化の係数は営業日数で事前に固定します。365は使いません。門に使う指標は、下の論文の実装が数値例と一致してからです。実験Bの最大値は、この条で捨てる数です。

    近い実験（本人）: B

17. 無リスク金利は、この無料データにありません。引く金利は0と事前に書き、その旨を結果に残します。記憶にある金利を引かないでください。0で引いた差を、金利超過のアルファと呼ばないでください。

    近い実験（本人）: C

18. 税引き前の損益を、手取りと書かないでください。税率は国税庁のページを私が見て、出典URLと確認日を別欄に書きます。記憶のパーセントは書きません。

    近い実験（本人）: C

19. 判定の門は、結果を見る前に空欄のない表にします。1つでも不合格なら不採用です。空欄が残っている実験は開始しません。門が食い違ったら、不採用の側を採ります。

    近い実験（本人）: C

20. 収益率を見る前に、次を数えます。収益率から作られる量は使いません。
    - 信号が計算できた日の割合
    - 建玉が常に全額、または常にゼロに張り付く日の割合
    - 主の相手との建玉の差
    - 年あたりの回転×コスト下限。これが、事前に書いた効果の大きさの3分の1を超えるなら、その実験は始めません
    - 主張する効果の大きさ。このサンプルの収益から書いてはいけません
    - フィルターなら、状態がオンになった回数。1つの出来事を除くと差の符号が変わるなら不採用です
    - この標本の長さと試行の上限で、合格線が到達できないなら、線は緩めません。実験を始めません
    - 合成データで、未来を混ぜた実装は落ち、エッジのない系列は合格しないこと

    近い実験（本人）: C

21. 検証の道具は、合成データで論文の数値例と一致してから実データに当てます。一致しない道具は使いません。実データで「有意になるか」を試し打ちした時点で、その試し打ちも1回の試行です。

    近い実験（本人）: C

22. この取引で損をする相手と、その相手が損を受け入れる理由を1文で言えない仮説は、登録しません。

    近い実験（本人）: C

23. 資料にない数字は埋めません。推測は推測と書きます。

    近い実験（本人）: C

24. 同じデータで、結果を見て仮説を出し直すのは1回までです。パラメータの微調整は、新しい仮説ではなく、元の試行に加算される再試行です。

    近い実験（本人）: C

25. 結果は、データとコードとライブラリの版のハッシュとともに、同じ手順で再計算できなければ、結果としません。否定的な結果も、同じ形式で残します。

    近い実験（本人）: C
